## Cliente de facturación "Gusher"
### Tecnologias usadas
- Nuxt 2.17.0
- Node 18
- Vue 2
- Vuetify
- Axios
- /api (Node/Express integrada) y modHarbour como backend

### Descripción
Cliente web para facturación electrónica
Incluye: 
- Facturación (Notas de Crédito, Refacturación, Cancelaciones, etc.)
- Consulta de Lotes
- Inventario por Lotes
- Traspasos
- Consulta de Compras
